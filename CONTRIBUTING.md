Contributions are welcome, large or small.

Before writing code, it is worth opening an
[issue](https://github.com/angelbana/ocelotVPN-windows/issues) to discuss what you
have in mind, especially for anything ambitious. That gives everyone a chance
to point you in the right direction, and to say whether someone is already
working on the same thing.

What helps a change go in quickly:

 - it builds on both Windows and Linux, since those are the two systems this
   project ships;
 - the interface keeps working with every theme, not only the one you use;
 - the commit message says what changes and why, in whole sentences.

The macOS client is a separate project and lives at
[ocelotVPN](https://github.com/mraliscoder/ocelotVPN); changes for it belong
there.
