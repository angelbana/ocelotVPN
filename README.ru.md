# Ocelot для Windows

[![EN](https://img.shields.io/badge/lang-EN-6c757d?style=flat-square)](README.md)
[![RU](https://img.shields.io/badge/lang-RU-0b5fff?style=flat-square)](README.ru.md)

Клиент для VPN-серверов, говорящих по протоколу Cisco AnyConnect, построенный
на OpenConnect. Программа делается под Windows; заодно собирается образ
приложения под Linux.

Для macOS есть отдельный клиент:
[ocelotVPN](https://github.com/mraliscoder/ocelotVPN).

Программа выросла из форка
[OpenConnect VPN GUI](https://gui.openconnect-vpn.net/), и с тех пор её
интерфейс переписан на Qt 6 и QML.


## Для чего она

Простой и короткий путь в VPN. Тем, для кого она написана, не нужно знать, что
такое устройство tun, и программа об этом не спрашивает.

### В один щелчок

 - подключение к новому серверу;
 - подключение к сохранённому серверу;
 - отключение;
 - просмотр журнала.

### Она помнит за вас

 - пароль профиля — его хранит сама Windows, а не мы;
 - подключение само: при запуске программы, при входе в Windows и заново
   после обрыва связи;
 - запуск сам, задачей планировщика, чтобы Windows не спрашивала разрешение
   при каждом входе.

Ещё она живёт в области уведомлений: один щелчок открывает небольшое окно с
состоянием, одной кнопкой и профилями — на обычный день этого хватает.

### Три темы и два языка

Ночная, дневная и оцелотовая: они меняют только цвета, расположение во всех трёх
одинаковое. Интерфейс говорит по-русски и по-английски, по умолчанию следует за
Windows и переключается без перезапуска.

### Безопасность

Программа рассчитана на нетехническую аудиторию, поэтому решения о
безопасности не перекладываются на пользователя без крайней необходимости.

#### Проверка сертификата сервера

У SSL VPN-серверов, с которыми работает openconnect, исторически встречались
сертификаты с неверными именами узлов и сертификаты вне общедоступной
инфраструктуры открытых ключей. Поэтому программа:

 1. пробует обычную проверку по инфраструктуре открытых ключей — если она
    удалась, сервер подтверждён;
 2. иначе переходит к проверке в духе SSH, когда открытый ключ сервера обязан
    остаться таким же, как в прошлый раз.


## Что вы получаете

| Система               | Поставка                                          | Подпись |
|-----------------------|---------------------------------------------------|---------|
| Windows 10 и новее    | установщик                                        | да      |
| Linux, x86-64         | образ приложения: один файл, несущий Qt с собой   | нет     |

Установщик под Windows и программа внутри него подписаны по Authenticode и
снабжены меткой времени, поэтому Windows называет издателя, а не предупреждает
о неизвестном.

Образ приложения под Linux был запущен на Ubuntu 24.04 — системе более старой,
чем та, где он собран, и неспособной запустить голую сборку вовсе; ради этого
образ и несёт Qt с собой.

Что каждая поставка требует от системы, описано в
[Запуске опубликованных сборок](docs/running.ru.md).
